Boost subset
============

The Boost 1.81.0 headers that Shade builds against. The set is the one the 1.71.0
subset held, copied from the 1.81.0 release, plus the headers that the 1.81.0 includes
of Shade and Umbra reach; it was not produced by `bcp`. Boost is licensed under the
Boost Software License 1.0; see LICENSE_1_0.txt.
